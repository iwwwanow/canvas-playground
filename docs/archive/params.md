# Toast Parameters & Recommendations

## Общие рекомендации по размеру входного изображения

| Использование | Рекомендуемый размер | Примечание |
|---|---|---|
| Быстрый тест | 480×270 | Минимальная нагрузка |
| Стандарт | 640×360 | Баланс скорости и детали |
| Высокое качество | 1280×720 | Медленно на CPU, для финала |
| Проектор/экспорт | 1920×1080 | Только с GPU (WebGL) |

---

## `hue-scan`

**Описание:** Вырезает срез по оттенку, добавляет хромашум, рендерит на цветной фон.

| Параметр | Тип | Default | Диапазон | Рекомендация |
|---|---|---|---|---|
| `hue` | number | 0 | 0–359 | Оттенок среза в градусах HSV |
| `noizeDeviation` | number | 0.3 | 0–1 | 0.1–0.4 для тонкого эффекта |
| `background` | hex | `#ffffff` | любой hex | Тёмный фон (#000, #1a1a2e) выглядит эффектнее |

**CLI пример:**
```bash
toast run hue-scan -i input.jpg -o out.jpg --param hue=180 --param background=#000000
```

---

## `hue-cycle`

**Описание:** Многоканальная хью-анимация с серой базой и перспективным Y-вращением.

| Параметр | Тип | Default | Рекомендация |
|---|---|---|---|
| `fps` | number | 30 | 24 для кино, 30 для веба |
| `format` | string | mp4 | `mp4` или `gif` |
| `totalFrames` | number | LCM каналов | Кратно LCM (120, 240, 360) |
| `yMaxAngle` | number | π×0.05 | 0.03–0.08 для мягкого эффекта |
| `focalLength` | number | 600 | 400–800 |
| `channels` | array | 5 каналов | Не более 6 каналов на 640px |

**Рекомендуемые входные изображения:** Портреты, объекты с насыщенными цветами, 480×270–640×360.

**CLI пример:**
```bash
toast run hue-cycle -i input.jpg -o out.mp4 --param fps=24 --param totalFrames=120
```

## `hue-noise`

**Описание:** Добавляет шум в канал оттенка.

| Параметр | Тип | Default | Рекомендация |
|---|---|---|---|
| `deviationCoefficient` | number | 0.05 | 0.02–0.1 |
| `preserveAlpha` | boolean | true | — |

## `mosaic`

**Описание:** Мозаичная замена цветовых пятен видео на медиафайлы. Пайплайн: постеризация → прямоугольники → ассеты → видео.

### Параметры сегментации (`mosaic frames`)

| Параметр | Тип | Default | Рекомендация |
|---|---|---|---|
| `tones` | number | 6 | 4–8. Меньше = крупнее пятна |
| `hues` | number | 6 | 4–8. Меньше = крупнее пятна |
| `minRegionSize` | number | 200 | px. Фильтр шума. 100–500 |
| `maxAspect` | number | 7 | Макс. пропорция прямоугольника (7:1) |
| `overshoot` | number | 0.08 | Допустимый выход за границу пятна (8%) |

**Гранулярность:**
- Крупные пятна (мало деталей): `tones=4 hues=4`
- Средняя: `tones=6 hues=6` (default)
- Мелкие пятна (много деталей): `tones=8 hues=8`

**Рекомендуемый входной видеофайл:**
- Формат: MP4, H.264
- Размер: 640×360 (тест) или 1280×720 (финал)
- Длина: 5–30 сек
- Контент: объекты с выраженными цветовыми зонами (портреты, пейзажи с небом/зеленью)

### Параметры рендера (`mosaic render`)

| Параметр | Тип | Default | Рекомендация |
|---|---|---|---|
| `duration` | number | 5 | секунды выходного видео |
| `fps` | number | 24 | 24 для кино |
| `format` | string | mp4 | mp4 / gif |

**Ассеты:**
- Количество: ≥ количества уникальных классов цветов (обычно 16–30)
- Формат: JPG/PNG (статика), MP4/WebM (анимация), GIF, или папки с PNG-секвенцией
- Размер: 640×360 достаточно

**Полный флоу:**
```bash
toast mosaic frames -i input.mp4 -o ./frames/ --tones 6 --hues 6
toast mosaic collect-assets -o ./assets/ --count 24
toast mosaic render --segments ./frames/segments.json --assets ./assets/ -o result.mp4 --duration 10
```
