## Клипы из batch-out/inputs: нарезка + mondrian-отбор

### Цель

Разбить все видео из `batch-out/inputs` на короткие отрезки, прогнать mondrian-фильтр,
вручную отобрать лучшие клипы для монтажа.

### Скрипты

| скрипт | что делает |
|--------|-----------|
| `scripts/split-video.sh <input.mp4> [out_dir] [min_sec] [max_sec]` | нарезка одного видео на отрезки |
| `scripts/split-batch.sh [inputs_dir] [out_dir] [min_sec] [max_sec]` | нарезка всех видео в директории |
| `scripts/mondrian-clip.sh <clip.mp4> [out_dir]` | mondrian-рендер одного клипа |
| `scripts/mondrian-clip-batch.sh [clips_dir] [out_dir]` | mondrian-рендер всех клипов в директории |

### Параметры нарезки

- Длина отрезка: **случайная 1–5 сек** (min/max задаются аргументами)
- Разрешение: **max 540px** по ширине (`scale=min(iw,540):-2`)
- Аудио: убирается (`-an`)
- Кодек: `libx264 crf 23 preset fast`

### Параметры mondrian (те же что в финальном батче)

```
mosaic frames: --fps 15 --tones 12 --hues 12 --min-region 32
mosaic render: --mode solid --color-palette D40920,1B3F8B,F5C000 --bg-color FFFFFF
               --scale 540 --fps 15 --format mp4 --no-save-frames
```

### Директории

```
batch-out/clips/            ← нарезанные клипы (из split-batch.sh)
batch-out/clips-mondrian/   ← mondrian-рендеры клипов (из mondrian-clip-batch.sh)
```

### Workflow

```bash
# 1. Нарезать все видео (случайные 1–5 сек)
./scripts/split-batch.sh

# 2. Прогнать mondrian по всем клипам
./scripts/mondrian-clip-batch.sh

# 3. Просмотреть batch-out/clips-mondrian/ и отобрать нужные
```

Или по одному видео:
```bash
./scripts/split-video.sh batch-out/inputs/video-3.mp4
./scripts/mondrian-clip-batch.sh batch-out/clips batch-out/clips-mondrian
```

Или один клип:
```bash
./scripts/mondrian-clip.sh batch-out/clips/video-3-007.mp4
```

### Проблема со статичными изображениями

Для image-инпутов (webp) — 1 фрейм сегментов → всё время один и тот же лейаут → GIF
анимируется только за счёт смены ассетов в тайлах (flickering), без направленного движения.

**Задача**: решить как правильно подать статику в презентации — либо сделать motion в рамках
фильтра тоста, либо ограничиться видео-инпутами для анимированных примеров.

### Фичи для демонстрации

- `--mode solid` — плоские цвета, показывает сегментацию
- `--mode photo` — фото-тайлы без обработки
- `--tint-tiles [--tint-strength 0.5]` — overlay-tint, баланс текстуры и палитры
- `--gradient-map` — duotone: тёмные → цвет сегмента, светлые → белый
- `--hue-tiles` — замена оттенка, сохраняет яркость и насыщенность
- `--blur-tiles` — painterly размытие пропорционально размеру тайла
- `--boost-tiles` — контраст boost: светлые → белее, тёмные → темнее
- `--max-tile 64` — grid subdivision: крупные сегменты дробятся на ячейки 64px
